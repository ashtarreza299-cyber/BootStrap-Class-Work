# University Web Development Homework

This project is a simple web page developed as part of my university homework using **HTML, CSS, and Bootstrap**.

The purpose of this project was to practice fundamental web development concepts, improve my styling skills, and learn how to create a clean and structured web page.

## Technologies Used

- **HTML5** — Structuring the web page
- **CSS3** — Styling and layout
- **Bootstrap** — Responsive design and prebuilt UI components

## What I Learned

- Structuring web pages with HTML
- Styling page elements with CSS
- Using Bootstrap components and layout utilities
- Practicing front-end web development

## Project Status

This project was created for educational purposes as part of my university coursework.
